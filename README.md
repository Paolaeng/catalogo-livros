# Catalogo de Livros

Aplicacao Web simples para gerenciamento de um catalogo pessoal de livros.

Este projeto faz parte do trabalho final da disciplina de Versionamento de Codigo.

## Tecnologias

- Node.js
- Express
- EJS
- HTML
- CSS
- JavaScript
- JSON

## Como executar

Instale as dependencias:

```bash
npm install
```
